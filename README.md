# 多语言翻译核对工作流

本仓库用于沉淀一套可复用的多语言翻译核对方法，适用于脑图模板等图文内容的人工复审场景。

如果你是第一次上传自己的 GitHub 仓库，建议先看这两个文件：

- [第一次上传到 GitHub](./docs/第一次上传到GitHub.md)
- [审核标准与流程](./docs/审核标准与流程.md)

## 仓库目标

- 统一不同语种的审核口径
- 降低多轮审核中的重复劳动
- 固化问题记录方式和修改建议写法
- 方便团队成员直接复用

## 适用范围

- 英文
- 法语
- 德语
- 西班牙语
- 意大利语
- 葡萄牙语
- 韩语
- 日语
- 繁体中文
- 其他目标语言

## 核心原则

- 以中文模板为基准核对目标语言模板
- 采用宽标准，以是否影响阅读和理解为核心判断依据
- 不做母语润色级挑错，不追求唯一标准译法
- 存疑内容需要人工联网复审
- 未通过项的`问题说明`与`修改意见`必须编号并一一对应

## 新手最快开始

1. 阅读[审核标准与流程](./docs/审核标准与流程.md)，先统一审核口径。
2. 阅读[第一次上传到 GitHub](./docs/第一次上传到GitHub.md)，了解发布步骤。
3. 如果暂时不想公开，先按说明把仓库设为`Private`。
4. 把脱敏后的示例图片、模板文件、脚本放入对应目录。
5. 按[发布前自检清单](./docs/发布前自检清单.md)检查一遍。
6. 再上传到 GitHub。
