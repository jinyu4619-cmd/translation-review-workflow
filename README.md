# 多语言翻译核对工作流

这个仓库用于沉淀一套可复用的模板图翻译核对方法，适用于脑图模板、图文模板等需要人工复审的场景。

## 先记住这 3 件事

1. 只审核预览图中已明确标记为 `审核通过` / `验收通过`，且台账状态仍为 `未审核` 的模板。
2. 采用宽审核标准，只抓明显错翻、明显中文或其他语言残留、敏感或政治话题，不做母语润色级挑错。
3. 每个语种最终只交付两份 Excel：`检验进度台账.xlsx` 和 `未通过项.xlsx`。

## 新同事最短上手路径

1. 先看 [快速开始](./docs/快速开始.md)
2. 再看 [审核标准与流程](./docs/审核标准与流程.md)
3. 打开 `templates/` 复制模板开始填
4. 参考 `examples/` 看示例成品长什么样

## 你需要准备的输入

- 待审核图片文件夹
- 能确认审核范围的预览图或台账信息
- 中文模板图和目标语言模板图
- 可联网环境，用于人工复审存疑翻译

如果业务侧给你的文件夹里只有图片，没有辅助文件，也可以先自行整理配对信息，再进入审核。

## 最终交付要求

### `检验进度台账.xlsx`

至少包含：

- 序号
- 预览行号
- 中文图编号
- 外文图编号
- 模板名称
- 对应语种
- 审核状态
- 问题分类
- 备注

### `未通过项.xlsx`

至少包含：

- 序号
- 领取人
- 预览行号
- 中文图编号
- 外文图编号
- 模板名称
- 对应语种
- 中文模板图
- 外文模板图
- 审核结论
- 问题分类
- 问题说明
- 修改意见

补充要求：

- `中文模板图` 和 `外文模板图` 必须放实际图片，不能只写图片编号。
- `中文图编号` 和 `外文图编号` 只用于辅助定位原图。
- `问题说明` 和 `修改意见` 都必须加标号，并且一一对应。
- `修改意见` 必须直接写成 `原文 -> 建议改为`。

## 审核结论规则

- 出现 `①中文没翻译干净 / 其他语言残留` 或 `②词语翻译错误` 的任意一类问题，即判为 `未通过`。
- 仅存在 `③可改可不改，建议修改` 时，按 `通过` 处理。
