# templates

此目录建议放固定格式模板，目的是统一最终交付口径。

## 推荐文件

- `检验进度台账.xlsx`
- `未通过项.xlsx`

## 检验进度台账建议字段

- 序号
- 预览行号
- 中文图编号
- 外文图编号
- 模板名称
- 审核状态
- 问题分类
- 备注

## 未通过项建议字段

- 序号
- 领取人
- 模板名称
- 中文模板图
- 外文模板图
- 预览行号
- 中文图编号
- 外文图编号
- 审核结论
- 问题分类
- 问题说明
- 修改意见

## 问题分类建议

在宽审核标准下，`问题说明`和`修改意见`可优先按以下三类整理：

1. 中文没翻译干净 / 其他语言残留
2. 词语翻译错误
3. 可改可不改，建议修改

判定规则：

- 存在第 1 类或第 2 类问题时，必须列为`未通过`
- 仅存在第 3 类问题时，视为`通过`
- 第 3 类问题如需记录，可放在备注或优化建议中，不单独进入`未通过项`

## 重要要求

- `问题说明`必须编号
- `修改意见`必须编号
- 两者必须一一对应
- 每条`问题说明`应写明对应分类
- 每条`修改意见`应按相同分类和编号给出
- `修改意见`必须直接写成`原文 -> 建议改为`
