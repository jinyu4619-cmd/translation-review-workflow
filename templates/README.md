# templates

这个目录放固定格式模板，用来统一最终交付口径。

## 目录内文件

- `检验进度台账.xlsx`
- `未通过项.xlsx`

## 使用提醒

- `检验进度台账.xlsx` 用来记录本轮审核范围、审核状态和备注。
- `未通过项.xlsx` 只记录判定为未通过的模板。
- `未通过项.xlsx` 里的 `中文模板图` 和 `外文模板图` 必须放实际图片，不能只填图片编号。
- `中文图编号` 和 `外文图编号` 只是辅助定位原图，不能替代图片列。

## 问题分类

1. `①中文没翻译干净 / 其他语言残留`
2. `②词语翻译错误`
3. `③可改可不改，建议修改`

## 判定规则

- 只要出现第 1 类或第 2 类问题中的任意一项，就判为 `未通过`。
- 仅存在第 3 类问题时，按 `通过` 处理，不进入 `未通过项.xlsx`。

## 填写要求

- `问题说明` 必须编号。
- `修改意见` 必须编号。
- 两者必须一一对应。
- 每条 `问题说明` 里要写清对应分类。
- 每条 `修改意见` 必须直接写成 `原文 -> 建议改为`。
