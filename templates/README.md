# templates

此目录建议放固定格式模板。

## 推荐文件

- `检验进度台账.xlsx`
- `未通过项.xlsx`

## 字段建议

### 检验进度台账

- 图片编号
- 模板标题
- 中文模板图
- 目标语言模板图
- 对应语种
- 审核状态
- 备注

### 未通过项

- 图片编号
- 主题
- 模板标题
- 领取人
- 中文模板图
- 目标语言模板图
- 对应语种
- 问题说明
- 修改意见

## 问题分类建议

在宽审核标准下，`问题说明`和`修改意见`可优先按以下三类整理：

1. 中文没翻译干净 / 其他语言残留
2. 词语翻译错误
3. 可改可不改，建议修改

第 3 类用于放宽处理的情况，例如：

- 一词多义
- 轻微语法错误
- 表达不够自然但不明显影响阅读
- 可优化但不属于硬错误的情况

判定规则：

- 存在第 1 类或第 2 类问题时，必须列为`未通过`
- 仅存在第 3 类问题时，视为`通过`
- 第 3 类问题如需记录，可放在备注或优化建议中，不单独进入`未通过项`

## 重要要求

- `问题说明`必须编号
- `修改意见`必须编号
- 两者必须一一对应
- 每条`问题说明`应写明对应分类
- 每条`修改意见`应按相同分类和编号给出
- `修改意见`必须直接写成`原文 -> 建议改为`
