# examples

这个目录放脱敏后的最小示例，目的就是让同事点进来就知道怎么填。

## 目录内文件

- `sample_cn/`
- `sample_target/`
- `sample_检验进度台账.xlsx`
- `sample_未通过项.xlsx`

## 重点说明

- `sample_cn/` 和 `sample_target/` 放示例原图。
- `sample_未通过项.xlsx` 已直接嵌入对应图片，演示真实交付效果。
- 示例里保留了 `中文图编号` / `外文图编号` 列，但那只是辅助定位，不能代替图片本身。

## 注意事项

- 不要放真实业务结果。
- 不要放真实姓名、真实任务编号或未脱敏素材。
- 优先保留“看一眼就知道怎么用”的最小样例。
