# 发布前自检清单

上传 GitHub 前，建议逐项检查。

## 内容检查

- [ ] README 已写清仓库用途
- [ ] 审核标准与审核流程已整理完整
- [ ] 文档里没有明显乱码
- [ ] 示例目录中没有真实敏感数据
- [ ] 人员姓名、内部任务名、批次名已脱敏

## 文件检查

- [ ] 不需要公开的大文件已移除
- [ ] 本机缓存文件未混入
- [ ] `node_modules` 等依赖目录未放入仓库
- [ ] 预览图、输出图只保留示例所需内容

## 脚本检查

- [ ] 脚本不再依赖你的个人桌面路径
- [ ] 路径尽量改为相对路径或配置项
- [ ] 运行说明已写清楚

## 发布检查

- [ ] 已决定仓库先公开还是先私有
- [ ] 如果不想公开，已计划使用`Private`仓库而不是“共享密码”
- [ ] 如果要限制访问，已确认需要邀请哪些 GitHub 账号
- [ ] 已阅读许可证选择建议
- [ ] 已准备好仓库名称和简介
