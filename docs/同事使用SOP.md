# 模板翻译校对 Skill 使用 SOP

这份文档是写给第一次使用这个 skill 的同事看的。

目标只有一个：

把需要审核的文件夹交给 Codex，它自动按既定流程完成翻译校对，并把结果表输出回原文件夹。

## 一、这个 skill 是做什么的

这个 skill 用来审核多语种模板翻译图片。

你只需要提供一个待审核文件夹，skill 会自动完成这些事：

1. 识别总览图。
2. 判断本次是该语种第几批审核。
3. 筛选出本次真正需要审核的模板。
4. 按既定宽审核标准进行校对。
5. 输出两个 Excel 结果表回原文件夹。

最终会输出：

- `检验进度台账.xlsx`
- `未通过项.xlsx`

## 二、第一次使用前要做什么

### 方式一：同事已经把 skill 文件夹发给你

如果你拿到的是压缩包或文件夹，请这样操作：

1. 解压压缩包。
2. 找到里面的 `template-translation-review` 文件夹。
3. 把整个文件夹复制到你电脑的这个位置：

```text
C:\Users\你的用户名\.codex\skills\
```

4. 复制完成后，确认最终路径类似下面这样：

```text
C:\Users\你的用户名\.codex\skills\template-translation-review
```

5. 关闭 Codex，再重新打开。

### 方式二：从 GitHub 仓库获取

如果你是从 GitHub 获取这个 skill：

1. 下载或克隆仓库。
2. 找到仓库里的这个目录：

```text
skill\template-translation-review
```

3. 把整个 `template-translation-review` 文件夹复制到：

```text
C:\Users\你的用户名\.codex\skills\
```

4. 关闭 Codex，再重新打开。

## 三、如何判断自己安装成功

打开 Codex 新对话后，直接输入下面这句测试：

```text
用 template-translation-review 检查这个文件夹：C:\你的待审核文件夹路径
```

如果 Codex 能开始识别文件夹内容，说明安装成功。

## 四、每次审核前要准备什么

每次审核时，你只需要准备一个文件夹。

这个文件夹里建议放：

1. 本次审核要用的总览图。
2. 本次审核要用的 PNG 图片。
3. 如果是后续批次审核，保留上一次生成的：
   - `检验进度台账.xlsx`
   - `未通过项.xlsx`

## 五、待审核文件夹怎么整理

建议按下面要求整理：

1. 一个文件夹只放一个语种的内容。
2. 当前文件夹只放“本批次最新图片”。
3. 总览图和 PNG 图片放在同一个总文件夹里。
4. 不要混入其他语种的图片。
5. 不要混入无关截图、历史废弃图片、聊天截图。
6. 如果是后续批次审核，尽量不要删除历史生成的两个 Excel。

说明：

- 首次审核时，可以没有台账。
- 首次审核时，skill 会只根据总览图识别需要审核的模板，并自动建立该语种 `第1批` 台账。
- 后续审核时，skill 会读取旧台账，继续判断本次属于第几批。

## 六、正式使用时怎么输入指令

最推荐直接复制这句话，把路径改成你自己的：

```text
用 template-translation-review 检查这个文件夹：C:\你的待审核文件夹路径，并把结果输出回原文件夹
```

例如：

```text
用 template-translation-review 检查这个文件夹：C:\Users\张三\Desktop\英语审核，并把结果输出回原文件夹
```

也可以用下面这句：

```text
请用 template-translation-review 审核这个文件夹：C:\Users\张三\Desktop\英语审核
```

## 七、skill 会按什么流程工作

收到你的文件夹后，skill 会自动按下面流程处理：

1. 扫描文件夹。
2. 识别总览图和图片文件。
3. 判断本次是该语种第几批审核。
4. 如果首次审核没有台账，就自动建立 `第1批` 台账。
5. 如果已有台账，就读取历史台账并补充新一批模板。
6. 先告诉你：
   - 本次是第几批审核
   - 本次需要审核多少模板
   - 预计多久完成
7. 正式开始审核。
8. 审核结束后，把结果写回原文件夹。

## 八、审核标准是什么

这是宽审核标准，不是特别严格的母语润色审核。

主要只看 3 类问题：

1. `①中文没翻译干净 / 其他语言残留`
2. `②词语翻译错误`
3. `③可改可不改，建议修改`

判定规则：

- 只要出现第 1 类或第 2 类问题，就判 `未通过`
- 如果只有第 3 类问题，就按 `通过` 处理

额外规则：

- 要检查是否存在明显中文。
- 要检查是否涉及敏感或政治内容。
- 原则上一个模板里应只有一种主要语言。
- 但少量英文在其他外语模板中可以放宽，只要不影响阅读。
- 遇到一义多翻时，只要表达成立且不影响阅读，可以通过。
- 如果只是截图没裁干净，边缘残留少量中文编辑框、工具栏、缩放栏、页码栏等软件界面，但不影响模板正文阅读，这种按截图问题处理，不按翻译问题判未通过。

## 九、结果出来后怎么看

审核完成后，回到原文件夹查看这两个文件：

### 1. 检验进度台账.xlsx

这个表记录所有模板的审核状态。

你重点看：

- 审核批次
- 模板名称
- 对应语种
- 审核状态
- 问题分类
- 备注

### 2. 未通过项.xlsx

这个表只记录未通过模板。

你重点看：

- 审核批次
- 领取人
- 模板名称
- 中文模板图
- 外文模板图
- 问题说明
- 修改意见

## 十、如何理解这两个结果表

### 台账表

- 所有模板都会进入台账表。
- 台账是累计记录，不是只看本次。
- 每个语种都会保留自己的批次信息，例如 `第1批`、`第2批`。

### 未通过表

- 只有判定为 `未通过` 的模板才会进入这个表。
- 表里应直接带中文图和外文图。
- `问题说明` 和 `修改意见` 必须编号并一一对应。

## 十一、常见情况说明

### 情况 1：这是第一次审核

正常现象：

- 文件夹里没有 `检验进度台账.xlsx`
- 文件夹里没有 `未通过项.xlsx`

这时 skill 会：

1. 只看总览图。
2. 识别总览图中明确标记“审核通过”的模板。
3. 自动建立该语种 `第1批` 台账。
4. 开始本次审核。

### 情况 2：这是第二批或后续批次审核

这时你应尽量保留上一次生成的两个 Excel。

skill 会：

1. 读取旧台账。
2. 识别这次总览图中新进入审核范围的模板。
3. 把这些模板加入新批次。
4. 继续审核本次仍应处理的 `未审核` 项。

### 情况 3：旧台账里有未审核项，但当前文件夹没有对应图片

这是允许的。

skill 会保留这些项为 `未审核`，不会乱判结果。

## 十二、最常见的失败原因

如果 skill 没有顺利继续，最常见原因是：

1. 没有总览图。
2. 总览图不清晰，无法识别。
3. 当前文件夹缺少本次需要审核的图片。
4. 混入了太多无关图片。
5. 中文图和外文图无法对应。
6. 你给的不是文件夹路径，而是单张图片路径。
