# 安装与使用

这份文档讲的是：同事怎么把这个仓库当成 skill 装进 Codex，并开始使用。

## 你真正要安装的目录

仓库里真正的 skill 在这里：

- `skill/template-translation-review`

不是整个仓库都要装进 Codex，重点是这个 skill 文件夹。

## 安装方式 1：从 GitHub 仓库路径安装

如果你的 Codex 支持从 GitHub 路径安装 skill，优先用这种方式。

安装目标路径是：

- `skill/template-translation-review`

安装完成后，重启 Codex。

原因：

- 后续仓库有更新时更容易同步
- 同事不需要手动拆目录

## 安装方式 2：手动复制到本地 skills 目录

如果你暂时不走 GitHub 安装，也可以手动安装：

1. 下载这个仓库
2. 找到 `skill/template-translation-review`
3. 把整个文件夹复制到本地 Codex skills 目录

Windows 常见位置：

- `%USERPROFILE%\\.codex\\skills\\template-translation-review`

复制完成后，重启 Codex。

## 安装后怎么触发

在 AI 对话框里直接输入待检文件夹路径即可，例如：

```text
用模板翻译核对 workflow 检查这个文件夹：
C:\你的路径\英语测试
```

或者：

```text
按翻译核对流程处理这个文件夹，并把结果写回原文件夹：
C:\你的路径\英语测试
```

## 待检文件夹要求

待检文件夹建议满足这些条件：

- 顶层直接放图片，不要再套二级子文件夹
- 同时包含总览图和待检模板图
- 总览图文件名最好包含 `总览`、`预览`、`overview`、`ledger`、`台账`、`汇总`
- 尽量只放当前批次图片

## skill 会自动做什么

1. 扫描文件夹中的图片
2. 先锁定总览图
3. 只筛出“总览中已通过、但仍未审核”的模板
4. 给出本次待审数量和预计完成时间
5. 按宽审核标准执行核对
6. 把结果输出成两个 Excel 到原文件夹

## skill 的两个输出文件

- `检验进度台账.xlsx`
- `未通过项.xlsx`

补充说明：

- 如果原文件夹里已经有同名文件，新结果会覆盖旧文件
- 建议每轮审核前确认是否需要先备份旧结果
