# 仓库结构建议

当前仓库建议按下面理解：

```text
translation-review-workflow/
├─ README.md
├─ CONTRIBUTING.md
├─ docs/
├─ examples/
├─ templates/
├─ scripts/
├─ outputs/
└─ skill/
   └─ template-translation-review/
      ├─ SKILL.md
      ├─ agents/
      ├─ references/
      └─ scripts/
```

## 各目录职责

- `skill/`
  - 真正要安装给同事使用的 Codex skill
- `docs/`
  - 安装说明、快速开始、审核标准
- `examples/`
  - 脱敏示例图和示例输出
- `templates/`
  - 参考模板
- `scripts/`
  - 仓库级辅助脚本
- `outputs/`
  - 可公开的演示输出或测试输出

## skill 内部职责

- `SKILL.md`
  - 定义 skill 在什么场景触发、按什么流程执行
- `references/`
  - 放审核规则、输出结构等参考说明
- `scripts/`
  - 放扫描输入文件夹、导出 Excel 等脚本
- `agents/openai.yaml`
  - 放 skill 在 UI 中显示的名称和默认提示

## 当前推荐维护顺序

1. 先维护 `skill/`
2. 再维护 `docs/`
3. 再维护 `examples/` 和 `templates/`
