# 仓库结构建议

建议将仓库整理成下面结构：

```text
translation-review-workflow/
├─ README.md
├─ CONTRIBUTING.md
├─ docs/
├─ examples/
├─ templates/
├─ scripts/
└─ outputs/
```

## 目录说明

- `docs/`
  - 放审核标准、审核流程、快速开始、FAQ 等文档
- `examples/`
  - 放脱敏后的最小示例数据，帮助新同事快速看懂输入长什么样
- `templates/`
  - 放`检验进度台账.xlsx`和`未通过项.xlsx`模板，帮助统一交付格式
- `scripts/`
  - 放辅助配对、结果导出、预览检查等脚本
- `outputs/`
  - 放样例输出结果，便于同事对照最终交付长什么样

## 推荐补充内容

- `examples/`
  - 1 组脱敏中文图
  - 1 组脱敏目标语言图
  - 1 份示例版`检验进度台账.xlsx`
  - 1 份示例版`未通过项.xlsx`
- `templates/`
  - 交付模板
  - 模板字段说明
- `scripts/`
  - 配对脚本
  - Excel 生成脚本
  - 结果预览脚本
- `outputs/`
  - 脱敏后的样例交付结果

## 推荐补充文件

- `.gitignore`
- `CONTRIBUTING.md`
- 如未来转公开仓库，再补`LICENSE`
