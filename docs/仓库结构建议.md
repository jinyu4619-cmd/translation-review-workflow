# 仓库结构建议

建议将仓库整理成下面结构：

```text
翻译核对工作流_GitHub版/
├─ README.md
├─ docs/
├─ examples/
├─ templates/
├─ scripts/
└─ outputs/
```

## 目录说明

- `docs/`
  - 放审核标准、审核流程、GitHub 发布说明、FAQ 等文档
- `examples/`
  - 放脱敏后的最小示例数据
- `templates/`
  - 放`检验进度台账.xlsx`和`未通过项.xlsx`模板
- `scripts/`
  - 放生成台账、整理截图、辅助校验的脚本
- `outputs/`
  - 放样例输出结果，便于同事对照

## 推荐补充文件

- `.gitignore`
- `LICENSE`
- `CONTRIBUTING.md`
