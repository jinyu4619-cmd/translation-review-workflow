# 快速开始

这份文档面向已经安装好 skill 的同事。目标是让你 3 分钟内知道怎么触发它。

## 第 1 步：准备待审文件夹

把本轮要审核的内容放进同一个文件夹里：

- 中文模板图
- 目标语言模板图
- 如果有总览图，也可以一起放，但现在只作为辅助参考
- 如果是后续批次，把上一次生成的 `检验进度台账.xlsx` 和 `未通过项.xlsx` 一起保留在文件夹里

建议：

- 不要混入其他语种图片
- 不要混入无关截图
- 不要混入历史废弃图片

## 第 2 步：在 AI 对话框里输入文件夹路径

直接说类似下面的话：

```text
用 template-translation-review 审核这个文件夹：
C:\你的路径\某语种文件夹
```

或者：

```text
检查这个文件夹，并把结果写回原文件夹：
C:\你的路径\某语种文件夹
```

## 第 3 步：skill 会自动执行这些事

1. 扫描文件夹中的图片和历史结果表。
2. 判断本次是首次审核还是后续批次。
3. 直接把当前文件夹里的模板图作为本批待审范围。
4. 先给出本次待审数量、预计完成时间和批次信息。
5. 按宽审核标准开始核对。
6. 自动输出两个 Excel 回原文件夹。

## 第 4 步：查看输出结果

skill 完成后，原文件夹里会出现：

- `检验进度台账.xlsx`
- `未通过项.xlsx`

其中：

- `检验进度台账.xlsx` 记录所有审核结果。
- `未通过项.xlsx` 只记录未通过项。
- 后续批次新增未通过项，会继续追加在旧的 `未通过项.xlsx` 下面。

## 第 5 步：重点检查未通过项

打开 `未通过项.xlsx` 时，重点看这几项是否都有：

- 领取人
- 模板名称
- 中文模板图
- 外文模板图
- 问题说明
- 修改意见

并确认：

- `问题说明` 和 `修改意见` 都有编号。
- 两者一一对应。
- 修改意见写得足够具体，能直接交给修改人执行。

## 如果 skill 停下来不继续

最常见原因有：

- 当前文件夹里没有可配对的中文图和外文图。
- 中文图和外文图对应关系不清楚。
- 目标语言图缺失。
- 混入了太多无关图片。

这时按提示补充信息，再重新执行即可。
