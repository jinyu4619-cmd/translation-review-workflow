# 审核标准与流程

## 审核标准

- 适用范围：适用于所有目标语言模板，不限于英文。
- 审核对象：只审核预览图中已明显标记为`审核通过`或`验收通过`，且台账中状态仍为`未审核`的模板。
- 审核基准：以中文模板为基准，对照目标语言模板进行核对。
- 审核口径：采用宽标准，以`是否影响阅读和理解`为核心判断依据；不做母语润色级挑错，不追求唯一标准译法。
- 一义多翻：同一中文内容允许存在多种正确译法；只要语义基本正确、表达成立、不影响阅读，即可判为通过。
- 存疑复审：因创作者使用的翻译软件不同，AI 或初审可能误判；遇到存疑内容时，必须人工联网检索目标语言真实用法后再判断；若检索后属于可接受表达，不记问题。
- 语言原则：一个目标语言模板原则上应只出现一种主要语言。
- 英文例外：除英文模板外，其他外语模板中允许少量英文存在，如软件名、产品名、常见缩写、国际通用术语等；前提是不影响阅读理解。
- 判定`未通过`的情形：明显错翻；明显中文残留；明显非目标语言残留且影响理解；涉及目标语言国家的敏感或政治话题；对繁中类模板，明显简体残留或简繁混排且影响阅读。
- 关于界面元素：单纯的边框、装饰图标、无语言信息的界面元素本身不单独构成问题；但如果最终交付图中仍保留带有中文或其他非目标语言文字的软件工具栏、标签页、状态栏、按钮文案等，则按`中文没翻译干净 / 其他语言残留`处理。
- 不判`未通过`的情形：轻微不够地道但能看懂；轻微语法、搭配或风格问题但不影响理解；不同翻译软件导致的可接受表达差异；少量可接受英文。
- 记录原则：只有`未通过`项进入`未通过项.xlsx`；通过项只更新`检验进度台账.xlsx`，不额外输出第三份优化文档。
- 问题分类要求：在宽审核标准下，问题说明可优先按三类归纳。①`中文没翻译干净 / 其他语言残留`；②`词语翻译错误`；③`可改可不改，建议修改`。第三类用于一词多义、轻微语法错误、表达可优化但不明显影响阅读的情况，属于放宽处理后的建议项。
- 通过与未通过判定规则：只要存在第 1 类或第 2 类问题中的任意一项，即判定为`未通过`；如果仅存在第 3 类问题，则按`通过`处理，不列为`未通过`项。
- 问题说明要求：`问题说明`必须加标号，统一使用`1. 2. 3.`；一个编号只写一个具体问题，编号数量应能直接看出问题总数；每条问题说明中应写出对应的大致分类。
- 修改意见要求：`修改意见`必须加标号，且与`问题说明`使用同一套编号；每个编号必须直接写明`原文 -> 建议改为`，不能只写“修改”“优化”“调整表达”“重写”；修改意见也应按上述三类对应给出。
- 对应关系要求：`问题说明`与`修改意见`必须一一对应；问题说明里列出的每一个问题，都必须在修改意见里给出明确改法；问题数量与修改数量必须一致，不能遗漏。

## 审核流程

1. 从预览图中筛出已明显标记`审核通过`或`验收通过`的模板。
2. 与台账比对，只保留状态为`未审核`的模板作为本轮审核对象。
3. 审核前先统计本次待审模板数量，并预估完成时间。
4. 建立中文图与目标语言图的对应关系。
5. 连续两张同模板时，第 1 张为中文，第 2 张为目标语言。
6. 连续三张同模板时，第 1 张为中文，第 2 张为中间版本跳过，第 3 张为目标语言。
7. 不允许机械按奇偶编号配对；目标语言图未产出的，不进入本轮审核。
8. 允许先自行生成辅助配对文件；即使业务方只给图片，也可以先整理辅助信息再审核。
9. 以中文模板为基准逐项核对目标语言模板。
10. 对存疑译法进行人工联网复审；确认属于可接受表达或一义多翻的，不记问题。
11. 先按三类问题做归类判断；只要出现第 1 类或第 2 类问题，即判定为`未通过`；如果仅有第 3 类问题，则按`通过`处理。
12. 对判定为`未通过`的模板，按编号填写问题说明和修改意见；问题说明中注明所属分类，修改意见按相同分类和编号逐条给出改法。
13. 输出前检查问题说明编号数与修改意见编号数是否一致，是否逐条对应，是否存在“写了问题但没给改法”的情况。
14. 审核完成后，将结果同步到`检验进度台账.xlsx`；仅将`未通过`项写入`未通过项.xlsx`。

## 交付要求

### 审核前需先输出

- 本次需要审核的模板数量
- 预计完成时间

### 最终交付文件

- `检验进度台账.xlsx`
- `未通过项.xlsx`

### 检验进度台账建议字段

- 序号
- 预览行号
- 中文图编号
- 外文图编号
- 模板名称
- 审核状态
- 问题分类
- 备注

### 未通过项建议字段

- 序号
- 领取人
- 模板名称
- 中文模板图
- 外文模板图
- 预览行号
- 中文图编号
- 外文图编号
- 审核结论
- 问题分类
- 问题说明
- 修改意见

说明：

- `未通过项.xlsx`中应附上中文图和外文图，方便查阅和回溯。
- `未通过项.xlsx`中应写明领取人，方便后续分发和跟进。
- `问题说明`和`修改意见`都必须能直接交给修改人员执行。
- 如果只是第 3 类建议项，不单独进入`未通过项.xlsx`。

## 问题分类写法建议

可优先使用下面三类：

1. 中文没翻译干净 / 其他语言残留
2. 词语翻译错误
3. 可改可不改，建议修改

其中第 3 类用于宽审核标准下的放宽处理，例如：

- 一词多义但当前译法略弱
- 轻微语法错误
- 表达不够自然但基本能看懂
- 有优化空间，但不至于单独构成严重阅读障碍

判定规则：

- 只要出现第 1 类或第 2 类问题，即为`未通过`
- 仅出现第 3 类问题时，视为`通过`
- 第 3 类问题可作为备注或优化建议保留，但不单独构成`未通过`

## 示例格式

### 问题说明

1. 分类：中文没翻译干净 / 其他语言残留。原文中仍残留`XXX`，影响目标语言阅读。
2. 分类：词语翻译错误。`XXX`与中文原意不符，属于明显误译。
3. 分类：可改可不改，建议修改。`XXX`能大致看懂，但表达不够自然，建议统一优化。

### 修改意见

1. 分类：中文没翻译干净 / 其他语言残留。`XXX -> YYY`
2. 分类：词语翻译错误。`XXX -> YYY`
3. 分类：可改可不改，建议修改。`XXX -> YYY`
