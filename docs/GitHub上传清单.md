# GitHub 上传清单

上传 GitHub 前，建议按下面顺序准备。

## 必做项

1. 把审核规则整理成正式文档。
2. 准备可公开的最小示例数据。
3. 对真实图片、人员姓名、内部任务名进行脱敏。
4. 把脚本中的本机绝对路径改为相对路径或配置项。
5. 统一文档与脚本编码为`UTF-8`。
6. 固定输出模板字段结构。
7. 本地完整自测一次，确认不依赖个人电脑目录。

## 建议项

1. 增加`.gitignore`
2. 增加`LICENSE`
3. 增加`CONTRIBUTING.md`
4. 增加样例运行结果截图
5. 把按语种硬编码的脚本改为可配置模式

## 推荐上传顺序

1. 先上传文档框架
2. 再上传示例素材和模板
3. 最后上传脚本和说明

## 上传后建议

1. 邀请同事按文档独立走一遍流程
2. 收集首次使用中的歧义点
3. 再回补 FAQ 或常见问题说明
