# 许可证选择建议

上传到 GitHub 前，最好考虑是否要加开源许可证。

## 先说明

我目前没有自动帮你放正式`LICENSE`文件，因为许可证一旦选错，后续可能带来使用范围上的误解。

## 如果你只是想先给同事看

可以先不放正式许可证，或者先把仓库设为`Private`。

## 如果你准备公开分享

常见选择：

- `MIT`
  - 最宽松
  - 适合流程文档、简单脚本、工具型仓库
- `Apache-2.0`
  - 也比较常见
  - 对专利条款更完整
- `CC BY 4.0`
  - 更常用于文档内容

## 对你这个仓库的建议

如果这个仓库主要是：

- 审核文档
- 模板说明
- 少量辅助脚本

比较常见的做法是：

- 代码部分用`MIT`
- 文档部分也沿用同一个许可证

如果你现在还不确定，最稳妥的做法是：

1. 先把仓库设为`Private`
2. 等内容整理成熟后，再补正式`LICENSE`
